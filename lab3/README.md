# Лабораторная работа 3: Реализация коллекций и интерфейсов

## Описание

Реализация простых коллекций в C# (.NET) с изучением интерфейсов коллекций и их контрактов.

## Реализованные классы

### 1. SimpleList
Класс `SimpleList` реализует интерфейсы:
- `IEnumerable` - поддержка перебора элементов (foreach)
- `ICollection` - базовые операции: добавление, удаление, подсчёт элементов
- `IList` - индексированный доступ, вставка, удаление по индексу

**Особенности:**
- Внутренне использует динамический массив (без готовых коллекций List и т.п.)
- Поддерживает: добавление, получение/установку по индексу, удаление, поиск индекса
- Автоматическое увеличение размера при необходимости

**Основные методы:**
- `Add(object? value)` - добавление элемента
- `Remove(object? value)` - удаление элемента
- `RemoveAt(int index)` - удаление по индексу
- `Insert(int index, object? value)` - вставка по индексу
- `IndexOf(object? value)` - поиск индекса элемента
- `Contains(object? value)` - проверка наличия элемента
- `Clear()` - очистка коллекции
- `CopyTo(Array array, int index)` - копирование в массив

### 2. SimpleDictionary<TKey, TValue>
Класс `SimpleDictionary<TKey, TValue>` реализует интерфейсы:
- `IDictionary<TKey, TValue>` - словарь, работа с ключами и значениями
- `IReadOnlyDictionary<TKey, TValue>` - поддержка только чтения
- `IEnumerable<KeyValuePair<TKey, TValue>>` - перебор пар ключ-значение

**Особенности:**
- Использует хеш-таблицу с цепочками для разрешения коллизий
- Автоматическое изменение размера при достижении коэффициента загрузки
- Поддерживает добавление, удаление и поиск по ключу

**Основные методы:**
- `Add(TKey key, TValue value)` - добавление пары ключ-значение
- `Remove(TKey key)` - удаление по ключу
- `ContainsKey(TKey key)` - проверка наличия ключа
- `TryGetValue(TKey key, out TValue value)` - безопасное получение значения
- `Clear()` - очистка словаря
- Индексатор `this[TKey key]` - доступ к значениям по ключу

### 3. DoublyLinkedList
Класс `DoublyLinkedList` реализует интерфейсы:
- `IList` - индексированный доступ, вставка, удаление по индексу
- `ICollection` - базовые операции
- `IEnumerable` - поддержка перебора элементов

**Особенности:**
- Двунаправленный связный список (каждый узел имеет ссылки на предыдущий и следующий элементы)
- Оптимизированный доступ к элементам (поиск с начала или с конца в зависимости от индекса)
- Эффективная вставка и удаление в любом месте списка

**Основные методы:**
- `Add(object? value)` - добавление в конец
- `Insert(int index, object? value)` - вставка по индексу
- `Remove(object? value)` - удаление элемента
- `RemoveAt(int index)` - удаление по индексу
- `IndexOf(object? value)` - поиск индекса
- `Contains(object? value)` - проверка наличия
- `Clear()` - очистка списка
